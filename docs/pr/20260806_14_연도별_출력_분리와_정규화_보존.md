## Summary

크롤러를 다시 실행하면 아티스트 표기 정규화가 조용히 사라지던 문제를 고친다. 정규화 결과를 `output/artist_mapping.json`에 영속화하고 `crawl.py`가 매 실행마다 그것으로 `artist_canonical`을 채우게 해, 재실행이 정규화를 지우는 대신 복원하도록 바꿨다. 함께 산출물을 연도별 폴더로 나눠 이전 연도가 덮어써지지 않게 했다.

## Changes

- `crawl.py` — `--year`로 시드 경로(`universities-<연도>.csv`)와 출력 폴더(`output/<연도>/`)를 유도. `--input`·`--output-dir` 제거
- `crawl.py` — `load_artist_mapping`·`save_artist_mapping` 추가 (원자적 쓰기, 파싱 실패·타입 불일치 시 중단)
- `crawl.py` — `build_lineup_rows(record, mapping)`가 매핑에서 `artist_canonical`을 채움. `mapping`은 필수 인자
- `crawl.py` — 연도 폴더 없는 예전 레이아웃을 감지해 마이그레이션 절차와 함께 중단하는 가드
- `enrich.py` — 전 연도 `raw/`를 훑고, 매핑에 없는 이름만 LLM에 전달. 매핑·`artists.csv`를 연도 공통으로 누적
- `enrich.py` — 프롬프트에 기존 정식 표기 목록을 실어 새 표기가 기존 아티스트에 붙게 함
- `enrich.py` — 신규 아티스트가 없어도 `lineup.csv`를 매핑에 맞춰 항상 갱신
- `enrich.py` — LLM 응답 중 이번에 물어본 이름의 매핑만 수용 (확정된 표기를 덮지 못하게)
- `serve.py` — `--year`로 볼 연도 고정. `artists.csv`는 연도 공통 `base_dir`에서 읽음
- `universities.csv` → `universities-2026.csv`
- `README.md`·`AGENTS.md` — 연도별 실행법, 경로, 정규화 보존·수동 교정 절차 반영

## Behavior Change

| 항목 | Before | After |
|---|---|---|
| `crawl.py` 재실행 후 `lineup.csv` | 정규화 107행이 원문으로 리셋 | 219행/정규화 107행 유지 |
| 시드 연도 변경 | 이전 연도 캐시·CSV가 덮어써짐 | `output/<연도>/`로 분리, 이전 연도 보존 |
| `enrich.py` 재실행 (신규 아티스트 없음) | 전체 목록을 다시 정규화 (실측 578초) | LLM 호출 없이 종료 (실측 5초 미만) |
| 실행 인자 | `crawl.py [--limit N]` | `crawl.py --year 2026 [--limit N]` |
| 검수 페이지 | `serve.py` | `serve.py --year 2026` |
| 예전 레이아웃으로 실행 | 캐시를 못 찾아 29곳을 조용히 재수집 | 마이그레이션 절차를 안내하고 중단 |
