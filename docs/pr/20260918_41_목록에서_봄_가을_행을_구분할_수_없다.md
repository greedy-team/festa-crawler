## ✨ 변경 사항

**검수 목록에 개최 월을 함께 보여줍니다.** 한 대학이 봄·가을 두 행을 가지면 목록에 같은 이름이 두 번 나오는데, `flag`와 대학 이름만 보여줘서 어느 쪽인지 알 수 없었습니다.

- 2026 시드에서는 서울대·건국대·서강대·서울과기대 네 곳이 두 줄입니다
- 특히 **서울대는 봄이 `루미네스(LUMINESCE)`, 가을이 `루미네스 LUMINES: Prologue`**라 상세를 열어도 헷갈립니다. `import_key`의 월을 봐야 갈립니다
- 재실행 버튼은 캐시 이름(`건국대학교-fall`)으로 행을 정확히 가리키므로 **동작은 원래 맞았습니다.** 표시만 빠져 있었습니다

시작일에서 월을 뽑고, 값이 없으면 `월 미상`으로 적습니다. `review.html` 한 파일만 바뀌며 **산출물 CSV와 API 응답은 그대로**입니다.
