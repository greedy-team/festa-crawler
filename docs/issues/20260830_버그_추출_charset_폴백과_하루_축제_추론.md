## 본문

## 🔍 현재 문제점

산출물의 빈 값 중 **둘은 크롤러가 채울 수 있는데 못 채우고 있다.** 그 탓에 백엔드 임포트에서 축제 2건이 `INVALID`로 떨어져 통째로 들어가지 않는다.

### (1) charset 없는 응답을 ISO-8859-1로 읽는다

`fetch.py`의 `html = resp.text`다. requests는 `Content-Type`에 `charset`이 없으면 RFC 2616대로 **ISO-8859-1로 폴백**하며 HTML의 `<meta charset>`은 보지 않는다.

한국외국어대학교가 채택한 소스 실측:

```
Content-Type      : text/html      ← charset 없음
resp.encoding     : ISO-8859-1     ← requests의 폴백
apparent_encoding : utf-8
meta charset      : UTF-8
```

- **실제 동작** — 한국외대 `start_date`가 빈다. 깨진 텍스트에서 `end_date`만 겨우 건졌다
- **예상 동작** — UTF-8로 디코딩되어 시작일·종료일이 모두 추출된다
- 영향 범위는 현재 채택된 소스 26곳 중 **1곳**이다. 나머지 25곳은 `Content-Type`에 charset을 명시한다. 다만 소스가 바뀌면 언제든 재발하고, 오류 없이 값만 비므로 드러나지 않는다

### (2) 하루짜리 축제의 종료일과 일차를 비운다

이화여자대학교 원문의 첫 문장이 사실상 전부다.

> 2026 이화여대 대동제 'Liberté : Moment'가 **5월 22일** 잔디광장에서 개최됩니다. NCT WISH, 원위, 한로로, 베이비돈크라이가 출연하며 …

- **실제 동작** — `end_date`가 `null`, 라인업 4행의 `day`가 전부 `null`
- **예상 동작** — 하루 축제이므로 `end_date = start_date = 2026-05-22`, `day`는 전부 `1`
- 원문에 정보가 없는 게 아니라 **하루짜리라는 사실에서 확정되는 값을 추론하지 않은 것이다**

## 🔄 재현 방법

1. `python crawl.py --year 2026`
2. `output/2026/festivals.csv` — 한국외대 행의 `start_date`, 이화여대 행의 `end_date`가 빔
3. `output/2026/lineup.csv` — 이화여대 4행의 `day`가 전부 빔

## 💡 해결 방안

- **(1)** `resp.encoding`이 없거나 `ISO-8859-1`이면 `resp.apparent_encoding`을 쓴다. `fetch_body` 한 곳
- **(2)** 추출 프롬프트에 두 규칙을 추가한다
  - 기간이 하루로 읽히면 `end_date = start_date`
  - 축제가 하루면 라인업 `day`는 전부 `1`
- **`SCHEMA_VERSION`을 2 → 3으로 올린다.** (2)가 추출 결과를 바꾸므로 재수집이 필요하다. 좌표 때(#18) 올리지 않은 것과 **반대 경우**다 — 그때는 시드 전용 필드라 LLM 결과가 한 글자도 안 바뀌었다
- 테스트 — charset 폴백 단위 테스트(헤더에 charset 없는 UTF-8 응답), 하루 축제 추출 케이스

## ⚠️ 먼저 알아둘 것

**`verify()`를 엄격하게 만들지 않는다.** 「필수 필드가 없으면 `flag`를 실패로 내려 백엔드에 `INVALID`가 안 가게 한다」는 안을 검토했다가 기각했다.

백엔드에 관리자 축제·라인업 교정 API가 생기면(`greedy-team/festa-backend#106`) **부분 데이터라도 넘어가야 사람이 마저 채운다.** verify를 조이면 서울대 12명·서울시립대 6명이 CSV에서부터 사라져 **채울 원재료조차 없어진다.** 크롤링은 초안 생성기이고 최종 신뢰는 사람이 담보한다는 설계 축을 그대로 따르는 판단이다.

**이 수정 뒤에도 남는 빈 값은 사람 몫이며 그게 정상이다.** 전부 원문에 없거나 소스가 존재하지 않는다.

| 대학 | 남는 빈 값 | 이유 |
| --- | --- | --- |
| 건국대학교 | 축제명 | 원문이 "2026 건국대학교 대학 축제"라고만 부른다 |
| 서울대학교 | 라인업 10/12행의 `day` | 원문이 "1부 공연 라인업"으로 나누고 일차를 밝히지 않는다 |
| 서울시립대학교 | 라인업 6/6행의 `day` | 6명이 한 문장에 나열되고 일차 구분이 없다 |
| 고려대학교 | 라인업 전체 | 입실렌티는 라인업을 사전 공개하지 않는 것이 전통 |
| 성신여대 · 숙명여대<br>동덕여대 · 삼육대 | 축제 전체 | 2026년 소스가 존재하지 않는다 |

**덤으로 확인할 것 — 건국대 `end_date`.** 본문 날짜 표기가 `2026.05.19`·`05.20`·`05.21`에 "3일간 진행되는"인데 추출값은 `2026-05-22`다. 이 이슈의 범위는 아니지만 재크롤 후 값을 대조할 가치가 있다.

## 📸 참고 자료
