## 본문

## 📝 현재 문제점

- 검수 화면 목록은 flag 와 대학 이름만 보여줍니다. 한 대학이 봄과 가을 두 행을 가지면 같은 줄이 두 번 나오고 어느 쪽인지 알 수 없습니다.
- 2026 시드에서는 서울대, 건국대, 서강대, 서울과학기술대 네 곳이 해당합니다. 목록에 서울대학교가 연달아 두 줄 있습니다.
- 서울대는 봄 축제와 가을 축제의 이름이 둘 다 루미네스 계열이라 상세를 열어도 헷갈립니다. import_key 의 월을 보고서야 갈립니다.
- 재실행 버튼은 캐시 이름으로 행을 정확히 가리키므로 동작은 문제가 없습니다. 표시만 빠져 있습니다.

## 🛠️ 해결 방안 / 제안 기능

- 목록 각 줄에 개최 월을 함께 보여 줍니다. 시작일에서 뽑고, 값이 없으면 미상으로 적습니다.
- 산출물과 API 는 바꾸지 않습니다. 화면 표시만 바뀝니다.

## ⚙️ 작업 내용

- 시작일이 빈 행에서도 깨지지 않는지 확인 (현재 고려대, 삼육대, 동덕여대, 한국외대가 해당)
