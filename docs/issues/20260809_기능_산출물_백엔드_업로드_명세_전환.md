# 🚀 [기능요청] 산출물을 백엔드 업로드 명세로 전환

## 📝 현재 문제점

- 백엔드가 크롤러 산출 CSV 3종을 일괄 업로드해 미리보기·반영하는 어드민 API 명세(크롤링 번들 업로드)를 작성 중인데, 현재 크롤러 산출물의 컬럼 구성·값 형식이 명세의 CSV 스펙과 다르다
- 명세가 요구하는 축제 소개, 해시태그, 이미지 목록, 외부인 입장·티켓 분류, 라인업 일차·순서, 아티스트 장르 등은 현재 수집·추출하지 않는다

## 🛠️ 해결 방안 / 제안 기능

- festivals.csv, lineup.csv, artists.csv 산출물을 명세의 컬럼 구성과 값 규칙(대문자 열거값, 파이프 구분, 날짜 형식)에 맞게 전환한다
- 명세에 새로 필요한 필드를 수집·추출 단계에서 채운다
- 기존 2026년 수집분은 전체 재크롤로 새 형식으로 재생성한다

## ⚙️ 작업 내용

- 산출물 3종의 컬럼 전환 및 값 형식 정리
- 신규 필드 추출(소개, 해시태그, 이미지 목록, 입장·티켓 분류, 일차·순서, 장르)
- 검수 화면을 새 컬럼 구성에 맞게 갱신
- 기존 수집분 재크롤 및 테스트 갱신
- 백엔드에 확인·전달할 항목 정리(플래그 값 목록, 인코딩, 명세 오탈자 등)
