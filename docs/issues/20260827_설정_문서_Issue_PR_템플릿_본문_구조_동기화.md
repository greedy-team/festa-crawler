## 🔍 현재 문제점

backend PR #74에서 확정된 Issue/PR 템플릿 최종 구조가 crawler 저장소에는 아직 반영되지 않았습니다.

- PR 템플릿에 리뷰 안내와 관련 Issue 자동 종료 근거가 없습니다.
- Issue 템플릿 5종의 본문 구조와 유형별 안내가 backend 최종본과 다릅니다.
- 세 저장소의 공통 작업 방식이 템플릿마다 다르게 안내됩니다.

## 💡 해결 방안 / 제안 기능

backend develop의 현재 최종 템플릿 6개를 기준으로 crawler의 기존 frontmatter와 자동화 설정을 보존하면서 본문 구조만 동기화합니다.

- 영향 범위: GitHub Issue/PR 작성 화면만 변경되며 크롤링 파이프라인 동작에는 영향이 없습니다.
- QA Issue 생성 봇 `PROJECT-COMMON-QA-ISSUE-CREATION-BOT.yaml`은 별도 Issue에서 세 저장소를 함께 수정하므로 이번 범위에서 제외합니다.
